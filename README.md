# BLUE JEANS · 숏폼드라마 엔진

1인 운영 숏폼 드라마 자동화 엔진. Shortform-Engine 대본 → 캐스팅 → 컷 → 스틸 → 영상 → 더빙 → 자막·사운드 → 편집 → 마스터.

## v0.6 (2026-11-12)
- 03 콘티 (기존 03 컷): 컷마다 '첫 장면'(스틸로 찍을 정지된 한 순간)과 '움직임'(영상에서 일어날 동작 하나)을 따로 씀.
  감독 AI가 콘티를 짠 뒤 감수 AI가 사진 한 장으로 찍히지 않는 컷(동작 둘, 기계 조작 섞임, 빠진 사물, 몸에 거는 소품)을 고치거나 나눔. 고친 곳은 화면에 표시.
  콘티를 다시 만들면 그 화의 기존 스틸·영상은 보관함(stills_old·clips_old)으로 옮김.
- 04 콘티 그림 (기존 04 스틸): 스틸·스틸 검수는 '첫 장면'을, 05 영상·영상 검수는 '움직임'을 씀. 그림이 하나 끝날 때마다 바로 저장.
- 02 캐스팅 시트: 확정 정면(직접 올린 그림 포함)을 기준으로 3/4·전신·뒷모습 3장 생성 또는 직접 올리기.
  컷의 각도·크기에 맞는 시트를 스틸 기준 그림으로 넣음 (뒷모습 컷 → 뒷모습, 측면 → 3/4, 와이드 → 전신, 이때 정면도 함께).

## v0.5 (2026-11-12)
- 03 컷: 한 화 14~16컷으로 잘게 (보통 컷 1.5~3초, 클라이맥스 한 컷만 4~6초 버티기). 영상 생성 컷 화당 7개까지, 정지 컷 3초 이하.
  말하는 얼굴은 정지 컷 2.5초 이하(립싱크 없음), 긴 대사는 듣는 사람 컷으로 이어 감.
- 연속성 금지 소품: 사원증·명찰·장신구·시계·이어폰·글자 있는 옷을 캐스팅 프로필·스틸·영상 지시문에서 처음부터 뺌. 이야기에 필요한 소품은 손에만.
- 04 스틸 자동 검수(Claude): 지시문 대상·동작·몸에 거는 소품·같은 얼굴·글자·손. 불합격이면 이유를 지시문에 붙여 2회까지 다시 만들고 합격한 그림을 확정.
  '검수만 하기'(그림 비용 없음), '불합격 컷 고치기', '이대로 통과'.
- 05 영상 자동 검수: 테이크의 첫·중간·마지막 장면 3장을 확정 스틸과 비교. 불합격이면 2회까지 다시, 그래도 불합격이면 '정지+카메라로 전환'. 화질 기본 1080p.
- 진행판: 검수 불합격이 남은 화는 빨간 테두리.
