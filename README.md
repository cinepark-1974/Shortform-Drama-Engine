# BLUE JEANS · 숏폼드라마 엔진

1인 운영 숏폼 드라마 자동화 엔진. Shortform-Engine 대본 → 캐스팅 → 컷 → 스틸 → 영상 → 더빙 → 자막·사운드 → 편집 → 마스터.

## v0.2 (2026-11-09)
- 01 대본: 작품 정리(인물 표기·장소 세트 통일, 설정 충돌 수정 제안), AI 숏폼용 정리본 txt·json 내보내기
- 03 컷: 회당 6~8컷 분할(Claude), 점검(컷 수·길이·정지 연속·클라이맥스·대사 길이·금지어), 스틸·영상 지시문 자동 조립, 남은 화 일괄 분할
- 샘플: 「단짠단짠」 정리본, EP1 컷 분할

## v0.1 (2026-11-09)
- 01 대본: docx·txt 업로드 → 화·장면·대사 자동 분리, 100화 진행판, 대본 보기
- 02 캐스팅: 인물(대사 많은 순) · 장소(등장 많은 순) 목록, Claude 프로필 초안, gpt-image-2 후보 생성, 직접 올리기, 1장 확정, 별칭·장소 합치기, 이미지 지시문 금지어 검사
- 03~09: 자리만 있음
