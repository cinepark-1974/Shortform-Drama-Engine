# BLUE JEANS · 숏폼드라마 엔진

1인 운영 숏폼 드라마 자동화 엔진. Shortform-Engine 대본 → 캐스팅 → 컷 → 스틸 → 영상 → 더빙 → 자막·사운드 → 편집 → 마스터.

## v1.2.2 (2026-11-14)

## v1.2.1 (2026-11-14)
- 05 영상: 정지화면이 영상으로 통과되던 문제 보강. 엔진이 직접 움직임을 잰다(카메라 줌·팬을 맞춘 뒤 남는 변화 = 인물의 실제 움직임).
  화면 정지·카메라만 움직임·읽기 실패는 Claude 판정 없이 바로 불합격 → 고쳐서 다시 만듦. 움직임 약함은 수치와 함께 Claude 가 판정(motion 항목, 애매하면 불합격).
  Claude 에게는 편집에서 실제로 쓰는 구간의 장면 4장을 보냄. 자동 검수를 꺼도 움직임 측정은 함.
- 05 영상: '이 화 영상 움직임 검사' 버튼 — 이미 만든 영상을 다시 재서 정지 컷을 찾아 '영상 만들기'로 다시 만들 컷으로 표시. 컷마다 움직임 수치 표시. 정지+카메라로 바뀐 컷 경고.
- 영상 지시문: '짧은 움직임'이 "나머지는 멈춤"으로 읽히던 문장을 "첫 1초 안에 분명히 보이는 동작"으로. 영상 금지어에 static image, frozen frame 등 추가.
- 08 편집: 클립에서 인물이 가장 많이 움직이는 구간부터 씀. 클립이 컷보다 짧으면 마지막 장면을 멈추는 대신 시작점 당김 → 최대 1.5배 느리게 → 남는 초만 멈춤(완성본 목록에 표시).

- 04 콘티 그림: '이 화 지시문 전체 새로 쓰기', 컷별 '지시문 새로 쓰기' (그림은 두고 지시문만 지금 규칙으로).

## v0.5 (2026-11-12)
