# BLUE JEANS · 숏폼드라마 엔진

1인 운영 숏폼 드라마 자동화 엔진. Shortform-Engine 대본 → 캐스팅 → 컷 → 스틸 → 영상 → 더빙 → 자막·사운드 → 편집 → 마스터.

## v0.9 (2026-11-13)
- 화별 준비물(브레이크다운): 03 콘티를 만들 때 그 화 대본에서 장소 시점·소품·분장의상을 먼저 뽑아 자동 등록. '이 화 준비물' 점검표에서
  기준 그림이 없는 것을 한 번에 만들어 확정(시점은 마스터, 분장·의상은 확정 얼굴을 기준 그림으로). 04 에서 준비물 그림이 없으면 경고.
- 장소 시점: 장소마다 카메라가 향하는 쪽의 세로 기준 그림(마스터를 기준으로 생성). 콘티가 컷마다 시점을 고르고, 그 그림이 컷의 배경.
- 장소에 놓인 소품(회의실 전화기 등): 그 장소의 컷에 설명·기준 그림이 자동으로 들어감. 소품 탭에서 종류·장소 지정.
- 엠블럼: 장소 기준 그림에 엠블럼이 있는 컷에만 그리도록 지시문 변경.

## v0.8 (2026-11-13)
- 분장·의상 (Make-up & Costume): 인물마다 머리·분장·옷 묶음(룩)을 여러 개 등록 (02 캐스팅 · 인물 칸). '기본' = 확정 캐스팅 그림의 차림.
  룩 그림은 확정 얼굴을 기준 그림으로 넣어 머리·분장·옷만 바꿔 만들거나 직접 올림. 룩마다 3/4·전신·뒷모습 시트.
- 03 콘티가 장면마다 인물의 룩 하나를 고름(컷의 looks). 한 장면 안에서는 코드가 하나로 통일. 대본상 필요한 새 룩(환자복 등)은 자동 등록.
- 04 콘티 그림: 룩 그림이 있으면 그 그림이 기준 그림, 없으면 얼굴만 기준 그림에서 가져오고 머리·분장·옷은 글 설명으로. 검수도 배정된 룩 기준.
- 확정 그림 zip 에 MAKEUP_COSTUME · PROP 폴더 추가.

## v0.7.1 (2026-11-13)
- 벽 엠블럼(회사 CI): assets/emblems 에 대성그룹 CI(글자 없는 도형) 등록. 이름에 '대성'이 들어간 장소에 자동 연결, 장소마다 바꾸거나 끌 수 있음.
  장소 마스터를 만들 때와 엠블럼이 보이는 컷(와이드·로고가 적힌 컷)에 기준 그림으로 들어감. 다른 회사 CI는 장소 탭의 엠블럼 보관함에 올림.

## v0.7 (2026-11-13)
- 소품 고정 (02 캐스팅 · 소품 탭): 손에 드는 소품(노트북 가방, 휴대폰 등)을 이름 + 영어 확정 설명 + 기준 그림으로 등록. 컷의 props 에 따라 같은 설명·같은 기준 그림이 모든 컷에 들어감.
  콘티를 만들 때 새 소품은 자동 등록. 예전 콘티는 첫 장면 문장에 소품 이름이 나오면 자동으로 붙음.
- 로고·간판: 장소 기준 그림이 있으면 긴 장소 설명문을 컷 지시문에 다시 넣지 않음(설명문 속 로고·게이트를 컷마다 새로 그리던 원인).
  벽 엠블럼은 장소 기준 그림의 모양·위치 그대로, 글자 없음. 콘티에서 로고·회사 이름을 쓰지 않고 '벽의 엠블럼'으로. 장소 지시문 초안에도 같은 규칙.
- 검수 항목 추가: set(장소·엠블럼이 기준 그림과 같은가), prop(소품이 기준과 같은 물건인가). 글자 검수를 엄격하게.
- 04 콘티 그림: '이 화 지시문 전체 새로 쓰기', 컷별 '지시문 새로 쓰기' (그림은 두고 지시문만 지금 규칙으로).

## v0.6 (2026-11-12)
- 03 콘티 (기존 03 컷): 컷마다 '첫 장면'(스틸로 찍을 정지된 한 순간)과 '움직임'(영상에서 일어날 동작 하나)을 따로 씀.
  감독 AI가 콘티를 짠 뒤 감수 AI가 사진 한 장으로 찍히지 않는 컷(동작 둘, 기계 조작 섞임, 빠진 사물, 몸에 거는 소품)을 고치거나 나눔. 고친 곳은 화면에 표시.
  콘티를 다시 만들면 그 화의 기존 스틸·영상은 보관함(stills_old·clips_old)으로 옮김.
- 04 콘티 그림 (기존 04 스틸): 스틸·스틸 검수는 '첫 장면'을, 05 영상·영상 검수는 '움직임'을 씀. 그림이 하나 끝날 때마다 바로 저장.
- 02 캐스팅 시트: 확정 정면(직접 올린 그림 포함)을 기준으로 3/4·전신·뒷모습 3장 생성 또는 직접 올리기.
  컷의 각도·크기에 맞는 시트를 스틸 기준 그림으로 넣음 (뒷모습 컷 → 뒷모습, 측면 → 3/4, 와이드 → 전신, 이때 정면도 함께).

## v0.5 (2026-11-12)
- 03 컷: 한 화 14~16컷으로 잘게 (보통 컷 1.5~3초, 클라이맥스 한 컷만 4~6초 버티기). 영상 생성 컷 화당 7개까지, 정지 컷 3초 이하.
  말하는 얼굴은 정지 컷 2.5초 이하(립싱크 없음), 긴 대사는 듣는 사람 컷으로 이어 감.
- 연속성 금지 소품: 사원증·명찰·장신구·시계·이어폰·글자 있는 옷을 캐스팅 프로필·스틸·영상 지시문에서 처음부터 뺌. 이야기에 필요한 소품은 손에만.
- 04 스틸 자동 검수(Claude): 지시문 대상·동작·몸에 거는 소품·같은 얼굴·글자·손. 불합격이면 이유를 지시문에 붙여 2회까지 다시 만들고 합격한 그림을 확정.
  '검수만 하기'(그림 비용 없음), '불합격 컷 고치기', '이대로 통과'.
- 05 영상 자동 검수: 테이크의 첫·중간·마지막 장면 3장을 확정 스틸과 비교. 불합격이면 2회까지 다시, 그래도 불합격이면 '정지+카메라로 전환'. 화질 기본 1080p.
- 진행판: 검수 불합격이 남은 화는 빨간 테두리.
